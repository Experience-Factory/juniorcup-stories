# Junior Cup Stories (EF Eupen)

Mini-app mobile pour créer les stories Instagram de la **Junior Cup 2026** d'Experience Factory Eupen : **Podium de la manche** et **Standings**, en catégories Mini et Junior.

Lien pour le personnel : https://experience-factory.github.io/juniorcup-stories/

- Le classement est lu en direct sur la page publique du Google Sheet (onglet Full ranking seulement).
- Les photos restent sur le téléphone : rien n'est envoyé sur un serveur.
- Pas de photo : un casque s'affiche à la place.

`index.html` est généré, ne pas le modifier à la main (source : `template.html` + `build.py`, gérés en local).
